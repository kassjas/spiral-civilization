# Spiral Civilization Encyclopedia

This directory is the GitHub map of the public **Spiral Civilization Encyclopedia**.

Public Encyclopedia: https://spiralcivilization.org/encyclopedia/

## Architecture

- **WordPress** is the current public representation of the Encyclopedia.
- **GitHub** preserves structured text, development history, and the traceable map of entries.
- Each public Encyclopedia entry has its own corresponding file in this directory.
- Future sub-concepts may become nested components when the knowledge architecture requires it.
- The older file `Encyclopedia` is retained as a **LEGACY SOURCE COPY** and is not the current public index.
- `Project Cockpit.md` is retained here for genealogy while its future placement in the operational Cockpit architecture remains under review.
